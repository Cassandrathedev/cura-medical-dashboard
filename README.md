# Cura-medical-dashboard
A responsive physician dashboard built with pure HTML, CSS and JavaScript. Designed to simulate a real-world telehealth interface for mental health practitioners.

# About
Cura is a frontend clinical dashboard concept designed for mental health clinics and medical practices. It brings together patient management, appointment scheduling, mood analytics, and data visualisation into a clean, accessible interface with full dark and light mode support.

# Features
	•	Dashboard — at-a-glance overview of patients, today’s appointments, mood averages and critical cases
	•	Appointments — interactive calendar with upcoming appointment list
	•	Patients — searchable and filterable patient records with mood scores and status badges
	•	Mood Tracker — Chart.js line charts showing individual and average mood trends
	•	Reports — weekly appointment bar chart and diagnosis breakdown doughnut chart
	•	Dark / Light mode — toggle with preference saved to localStorage
	•	Fully responsive — works on mobile, tablet, and desktop

# Built With
	•	HTML5
	•	CSS3 (Custom Properties, Flexbox, Grid, Media Queries)
	•	JavaScript (ES6+, localStorage)
	•	Chart.js — data visualisation
	•	Google Fonts — Inter + DM Mono
